    Update.exe won't follow the proxy

    Discord itself is going through the relay. Its updater (Update.exe) is .NET and only reads Windows' own proxy settings, so updates would go out direct. Start with system proxy routes every app on this machine through the relay - and turns itself back off two minutes after the updater goes quiet, so a download that takes a while still finishes.
